# Daftar-Maqom.txt
# Taruh di: https://teamkeringat.github.io/Mp3/Daftar-Maqom.txt
#
# FORMAT TIAP BARIS:   Judul | NamaFile.mp3
#   - Judul HARUS disusun:  <Rumus atau Praktek> <Maqom> <NamaTingkatan/NamaRumus>
#       Rumus   = untuk lipatan "Rumus Qoidah Nada"
#       Praktek = untuk lipatan "Praktek Nada dalam Surat"
#   - Maqom     : Bayati, Shoba, Hijaz, Nahawand, Rost, Jiharkah, Sika
#   - Tingkatan : Qoror, Nawa, Jawab, Jawabul Jawab
#   - Nama custom di belakang maqom (mis. Dasar, Asli, Asyiron, Ajami,
#     Kard Kurd, Iroqi, Quflah Bustanjar) dipetakan otomatis oleh menu
#     ke tingkatan yang sesuai (lihat peta alias di dalam HTML).
#   - NamaFile.mp3 otomatis diawali https://teamkeringat.github.io/Mp3/
#     (boleh juga ditulis link lengkap https://...)
#   - Baris berawalan # diabaikan.
#
# VARIASI: tambah angka di belakang judul, contoh:
#     Rumus Bayati Qoror 2 | Bayati-Qoror-Rumus-2.mp3
#   Maka di lipatan "Rumus Qoidah Nada" Bayati > Qoror muncul dua pemutar.
#
# Bila satu baris belum ditulis di sini, menu otomatis memakai nama file
#   <Rumus|Praktek>-<Maqom>-<Tingkatan>.mp3
# jadi cukup unggah MP3 dengan nama itu pun sudah bisa diputar.
